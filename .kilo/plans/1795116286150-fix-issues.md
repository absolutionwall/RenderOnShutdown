# Fix repository, correctness and packaging issues (RenderOnShutdown)

Follow-up to `.kilo/plans/1795116286145-init-clean-repo.md` (repo already cleaned at `aea842a`).
This plan addresses the P0/P1/P2 issues raised in review. NSIS (`makensis`) is **not installed**
on this machine, so the installer script must be made *correct by construction and lint-checked
by review*; runtime verification of `makensis` is out of scope here (documented as a manual step).

## Decisions

- **Implement the "render on shutdown" hook** (the app's namesake), using WPF
  `Application.SessionEnding` + Win32 `ShutdownBlockReasonCreate`/`Destroy`. Manual "Ejecutar
  ahora" keeps working. If no work is needed, let Windows proceed.
- Single-instance guard via named `Mutex` (second launch exits quietly).
- Atomic config save (temp file + `File.Move(overwrite)`), load-with-backup, never silently wipe
  on corrupt JSON without logging.
- Thread-safe, cancellable logging & processing; no `Dispatcher.Invoke` from background paths.
- Icons embedded as `<Resource>` and window `Icon` uses pack URI so they resolve in publish.
- NSIS: proper includes, working checkbox, version passed from the build, root derived from script
  location, `try/finally` in the PS1 helper.
- No `git push`. No commit unless explicitly requested later (current request: fix issues).
